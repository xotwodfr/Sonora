Interaction Behavior

1

Click-to-Seek

Tap any line to seek playback to that timestamp. Auto-follow immediately resumes. Touch and mouse supported.

2

Smart Auto-Follow

Lyrics scroll automatically with playback. When user manually scrolls, auto-follow suspends. Clicking a line restores it.

3

Emphasis Gradient

Active line is full opacity + scale. Past lines fade to 35%. Upcoming lines gradually increase opacity toward active.

Key Design Decisions

  • Reuse existing store: Add seek + scroll-suspend state to lyricsStore (no new player implementation)
  • Single component: Same LyricsView in FullScreenPlayer, NowPlayingBar opens it, MobileDock opens it
  • Touch-friendly: Minimum 44px tap targets, pointer-events on each line
  • No instrumental gaps: Lines without timestamps stay visible but aren't seekable
